# Lexicon

Open bilingual dictionaries between 12 languages: German, English, French, Spanish, Italian, Portuguese, Dutch, Russian, Chinese (Simplified and Traditional), Japanese and Korean.

Each direction (for example `de-en`) is one SQLite file. The files are published as release assets, not in the git tree.

Status: not released yet. The first release comes after the license check of every source.

## Licenses

Every gloss row names its source. Each release ships a `LICENSES.txt` with the name, URL, attribution and license of every source used in that release. Sources with non-commercial or no-derivatives terms are not included.
